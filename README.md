## 🛠️ Technologies Used

### **Frontend Core**
- **HTML5**: Semantic markup with ARIA accessibility features
- **CSS3**: Advanced animations, grid layouts, and responsive design
- **JavaScript (ES6+)**: Modern features including IntersectionObserver, RequestAnimationFrame

### **Frameworks & Libraries**
- **Tailwind CSS**: Utility-first CSS framework with custom responsive breakpoints
- **Chart.js**: Interactive data visualizations (bar charts, doughnut charts)
- **D3.js**: Advanced network diagrams with drag-and-drop interactions

### **Performance Optimizations**
- **Lazy Loading**: Images and heavy content loaded on demand
- **Deferred Loading**: Non-critical scripts loaded asynchronously
- **Preconnect Hints**: Optimized CDN connections
- **RequestAnimationFrame**: Smooth animations and transitions

### **Analytics & Monitoring**
- **Google Analytics 4**: User behavior and performance tracking
- **Custom Events**: Chart interactions, theme changes, section navigation
- **Performance Metrics**: Load time monitoring and optimization

- **Keyboard Navigation**: Full keyboard accessibility
- **Focus Management**: Visible focus indicators and logical tab order

## 🔧 Setup Instructions

### **For GitHub Pages Deployment:**
1. Fork or clone this repository
2. Replace `GA_MEASUREMENT_ID` in both HTML files with your Google Analytics ID
3. Update contact information and personal details
4. Enable GitHub Pages in repository settings
5. Your site will be live at `https://yourusername.github.io/repository-name/`

### **For Local Development:**
```bash
# Clone the repository
git clone https://github.com/yourusername/portfolio

# Navigate to directory
cd portfolio

# Open in browser (no build process required)
```
